## Опис проєкту

Консольна програма на Python для шифрування та розшифрування текстових повідомлень за допомогою класичних методів шифрування — шифру Цезаря та афінного шифру.

Програма підтримує український та англійський алфавіти та використовує персональні дані користувача для формування ключів.

## Функціонал

- Шифрування та розшифрування повідомлень за допомогою шифру Цезаря.
- Шифрування та розшифрування повідомлень за допомогою афінного шифру.
- Автоматичне визначення українського або англійського алфавіту.
- Формування персональних ключів на основі даних користувача.
- Порівняння результатів роботи шифрів.
- Brute force для підбору ключа шифру Цезаря.
- Підтримка великих і малих літер, пробілів та розділових знаків.

## Інструкція із запуску

1. Переконайтеся, що встановлено Python версії 3.8 або вище.
2. Клонуйте репозиторій або завантажте файл `app.py`.
3. Перейдіть до папки з лабораторною роботою: cd lab02
4. Запустіть програму
