Репозиторій для виконання лабораторних робіт з дисципліни **«Захист інформації»**.

**Група:** 6.04.122.010.23.2

## Структура репозиторію

- [`lab01/`](./lab01/) — **Лабораторна робота №1:** Аудит власної цифрової безпеки (Аналіз витоків даних, аудит приватності та консольний аналізатор паролів на Python).
- [`lab02/`](./lab02/) — **Лабораторна робота №2:** Класичні методи шифрування інформації (Дослідження шифрів Цезаря, Віженера та афінного шифру, а також програмна реалізація шифрування, розшифрування та brute force).
- [`lab03/`](./lab03/) - **Лабораторна робота №3:** Невидимі дані у власних файлах (дослідження стеганографії та програмна реалізація методу LSB для приховування й вилучення текстових повідомлень у зображеннях).
- [`lab04/`](./lab04/) - **Лабораторна робота №4:** Особистий цифровий підпис (дослідження засобів створення та перевірки цифрових підписів, а також розробка власної спрощеної системи на Python).
