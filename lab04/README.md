## Опис проєкту

Консольна програма на Python для практичної реалізації спрощеної системи цифрових підписів із використанням принципів асиметричного шифрування. Програма дозволяє генерувати пару ключів на основі персональних даних, створювати цифровий підпис документа за допомогою приватного ключа та перевіряти його за допомогою відкритого ключа. Також передбачено тестування виявлення змін документа та підроблення цифрового підпису.

## Функціонал

- **Генерація пари ключів** на основі персональних даних із використанням алгоритму SHA-256.
- **Формування приватного та відкритого ключів** за допомогою спрощеної математичної моделі RSA.
- **Обчислення SHA-256 хешу** документа для контролю його цілісності.
- **Створення цифрового підпису** за допомогою приватного ключа.
- **Перевірка цифрового підпису** з використанням відкритого ключа.
- **Виявлення змін документа** шляхом порівняння хешу з результатом перевірки підпису.
- **Тестування підроблення підпису** шляхом зміни його значення.
- **Збереження ключів і цифрового підпису** в окремих текстових файлах.
- **Обробка помилок** під час читання файлів та перевірки ключів.
- Зручне текстове меню для вибору дій.

## Структура репозиторію

- `app.py` — основний файл програми на Python.
- `test_document.txt` — текстовий документ для створення та перевірки цифрового підпису.
- `private_key.txt` — файл із даними приватного ключа (у результаті роботи програми).
- `public_key.txt` — файл із даними відкритого ключа (у результаті роботи програми).
- `signature.txt` — файл зі створеним цифровим підписом (у результаті роботи програми).

## Інструкція із запуску

1. Переконайтеся, що встановлено Python версії 3.8 або вище.
2. Додаткові бібліотеки встановлювати не потрібно — програма використовує стандартні модулі Python: `hashlib`, `math` та `os`.
3. Запустіть файл `app.py`:

   ```bash
   python app.py
   ```
