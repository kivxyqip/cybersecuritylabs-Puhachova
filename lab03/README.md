## Опис проєкту
Консольна програма на Python для практичної реалізації та дослідження стеганографічного методу LSB (Least Significant Bit). Програма дозволяє непомітно вбудовувати текстові повідомлення в молодші біти RGB-каналів цифрових зображень у форматі PNG, а також вилучати приховані дані з перевіркою їх цілісності та структури.

## Функціонал
- **Приховування текстових повідомлень** у зображеннях за допомогою методу LSB (RGB-канали).
- **Кодування тексту у формат UTF-8** із підтримкою кирилиці, латиниці та спеціальних символів.
- **Використання маркерів меж** (`<|START|>` та `<|END|>`) для точного визначення початку й кінця прихованого тексту.
- **Заголовок довжини повідомлення** (перші 32 біти) для контролю обсягу зчитаних даних.
- **Автоматичний розрахунок ємності** контейнера та відсотка її використання.
- **Формування детального технічного звіту** про процес приховування.
- **Вилучення та декодування** прихованого повідомлення зі стегоконтейнера.
- **Автоматична перевірка цілісності** та порівняння відновленого тексту з оригіналом.
- **Збереження вилученого тексту** у `.txt` файл.
- Зручне текстове меню для вибору дій.

## Структура репозиторію
- `app.py` — основний файл програми на Python.
- `original.png` — вихідне зображення-контейнер.
- `stego_image.png` — сформоване зображення з прихованим текстом.
- `extracted_message.txt` — текстовий файл із вилученим повідомленням.
